# 03 - Object-Oriented Programming

## Objetivo

En este módulo aprenderé los principios fundamentales de la Programación Orientada a Objetos (POO) utilizando Java.

Al finalizar este módulo seré capaz de:

- Proteger los datos de los objetos mediante encapsulación.
- Reutilizar código utilizando herencia.
- Aplicar polimorfismo para escribir programas más flexibles.
- Comprender el concepto de abstracción.
- Utilizar interfaces para definir contratos de comportamiento.
- Modelar relaciones entre objetos mediante composición.
