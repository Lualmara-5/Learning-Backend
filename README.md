# Learning Backend

Repositorio personal donde documento mi camino de aprendizaje en **Backend Development**, principalmente utilizando **Java y Spring Boot**.

Este repositorio nace con un objetivo: construir una base sólida de desarrollo backend mediante teoría, ejercicios y proyectos prácticos, avanzando progresivamente desde los fundamentos hasta la construcción de sistemas completos.

> **No busco solamente aprender conceptos. Busco entenderlos, aplicarlos y demostrar lo aprendido construyendo.**

---

## Objetivos

Durante este recorrido quiero aprender y fortalecer conocimientos en:

* Java
* Programación Orientada a Objetos
* Bases de datos y SQL
* HTTP y REST APIs
* Spring Boot
* Arquitectura y diseño de software
* Testing
* Seguridad
* Docker
* CI/CD y fundamentos de DevOps
* Cloud / AWS
* Buenas prácticas de desarrollo

El objetivo final es ser capaz de diseñar, desarrollar, probar y desplegar aplicaciones backend completas.

# Niveles

Este recorrido está dividido en niveles. Cada nivel representa una nueva etapa de conocimientos y, sobre todo, la capacidad de **construir cosas más complejas con lo aprendido**.

No se trata de títulos profesionales, sino de hitos personales dentro del aprendizaje.

### 🟢 Nivel 1 — Fundamentos

**Módulos 01 → 05**

> Aprender a programar y comprender los fundamentos de Java.

En este nivel se construye la base:

* Programación fundamental
* Java
* POO
* Java Core
* Estructuras de datos

🏆 **Meta:** poder resolver problemas utilizando Java de manera independiente.

---

### 🔵 Nivel 2 — Backend Development

**Módulos 06 → 10**

> Pasar de programar en Java a construir aplicaciones backend.

Se incorporan:

* SQL
* Bases de datos
* Git
* Gradle
* HTTP
* REST
* JDBC
* Spring Boot
* Spring Data JPA
* Hibernate

🏆 **Meta:** construir una REST API funcional utilizando Spring Boot y una base de datos.

---

### 🟣 Nivel 3 — Backend Engineering

**Módulos 11 → 13**

> Aprender a construir software más mantenible, seguro y confiable.

Se incorporan:

* Clean Code
* SOLID
* Design Patterns
* JUnit
* Mockito
* Testing
* Spring Security
* Autenticación y autorización
* JWT

🏆 **Meta:** transformar una API funcional en una aplicación backend más robusta y mantenible.

---

### 🔴 Nivel 4 — Software Architecture & Cloud

**Módulos 14 → 16**

> Pasar de construir aplicaciones a pensar en sistemas.

Se incorporan:

* Arquitectura por capas
* Arquitectura Hexagonal
* Domain-Driven Design
* Docker
* CI/CD
* GitHub Actions
* DevOps
* AWS

🏆 **Meta:** diseñar, desarrollar y desplegar un sistema backend completo aplicando arquitectura, testing, seguridad y automatización.

# Exercises

Los ejercicios tienen como objetivo practicar de forma aislada los conceptos aprendidos.


> **Concepto aprendido → ejercicio → aplicación en un proyecto.**

---

# Projects

Los proyectos son diferentes a los ejercicios.

Mientras que un ejercicio busca practicar un concepto específico, un proyecto combina conocimientos de diferentes módulos para construir una aplicación más completa.

Los proyectos aumentarán progresivamente de dificultad.

```text
projects/
│
├── 01-console-bank/
├── 02-student-management/
├── 03-library-api/
├── 04-jdbc-crud/
├── 05-spring-boot-api/
└── final-project/
```

La idea es que cada proyecto represente un nuevo salto en el aprendizaje.

# Filosofía

Este repositorio no pretende ser una colección de apuntes.

La idea es seguir un ciclo:

```text
  Aprender
     ↓
  Comprender
     ↓
  Practicar
     ↓
  Probar
     ↓
  Construir
     ↓
  Subir de nivel
```

Cada nuevo concepto debería terminar, siempre que sea posible, aplicado en código.
